How the mockup works

Planning measures: 80%+ on track; 50–79% needs attention; below 50% at risk. A missing denominator is shown as not applicable.

Workstream readiness: Each demo has six checks: owner, outcome, scope, milestone, a recorded dependency decision, and a delivery epic link. Readiness is completed checks divided by applicable checks.

Planning detail: A demo counts as complete only when all four required planning fields are present. A declined dependency is a recorded decision, but still needs a delivery response.

Previous-quarter close-out: Only completed demos count as closed. Carried-forward work remains visible for review, rather than silently counting as finished.

Daily refresh design: A production implementation would ingest source records daily, retain snapshots, and display each source’s actual as-of timestamp. This mockup makes no network requests and does not refresh production data.
